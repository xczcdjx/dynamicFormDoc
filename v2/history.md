# 历史更新

## 0.0.7（本地包）

当前文档根据源码与 PackageTest 中的 `dynamicformdjx-vue2-0.0.7.tgz` 编写，以下为本地版本能力说明，不代表 npm 发布时间。

- 输入组件：DynamicInput、DynamicCascadeInput、LoadedScroll。
- Element UI 表单：EleDynamicForm、内置渲染函数、useReactiveForm、useDyForm、useDecorateForm。
- 综合组件：ElePopupModal、EleZealCard、查询、表格、分页和行操作按钮。
- 辅助方法：分页、窗口尺寸与容器尺寸观测。

示例使用 Vue 2.7.16 和 Element UI 2.15.14。新增预览路由需要随 PackageTest 部署后才会在在线文档生效。
